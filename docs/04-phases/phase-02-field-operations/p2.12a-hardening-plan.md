# P2.12a hardening and non-functional tests (local and CI): slice plan

> [Docs index](../../README.md) › [04-phases](../README.md) › [Phase 2 plan](plan.md) · [Sub-phases](sub-phases.md#p212--hardening-non-functional-tests-shadow-run--exit-gate-m2) · [Tracker](tracker.md)

**In plain words:** prove, on our own machines and in CI, that Phase 2 holds at the shift change, after three days
offline, with a wrong tablet clock and against someone trying to cheat. Then rehearse the six demo steps and draft
the exit report. P2.12b (staging, device lab, shadow run at the pilot site) needs the Phase 1 carry-overs
([tracker §2](tracker.md#2-phase-1-carry-overs)) and is not in this plan.

## 1. Scope

| Item (sub-phases §P2.12a) | Test case | Where it runs |
|---|---|---|
| Shift-change burst: 300 tablets × 10 signed commands + 10 photos in 15 min; p95 batch < 1 s, no 5xx, queue ≤ 10 s | burst test of the M2 gate | nightly `load` job (k6), local `tests/load/run.sh` |
| 72 h offline: 400 entries and 300 photos queued, then a 3G network → all synced < 15 min, 0 loss | TC-P2-SYNC-006 | nightly browser job (Playwright, Chromium network throttling) |
| Tablet clock +3 h → `CLOCK_SKEW` | TC-P2-SYNC-008 | already covered: `ClockSkewTests`, `signShiftEntry.test.ts` (checked in slice 4) |
| Security review of sync and signatures: replay with a modified payload, forged enrollment, cross-tenant pre-signed URL, separation-of-duties bypass, public page enumeration | TC-P2-SIG-002…005, TC-P2-SYNC-012, TC-P2-VER-003 | backend and isolation suites (gaps filled in slice 4) |
| ZAP baseline extended to the public verification page and its API | hardening plan H-W1 | nightly `zap` job |
| Threat model statuses, demo rehearsal of the six steps, exit report draft | M2 gate | docs, browser E2E |

## 2. Slices

Each slice is one PR, tested, CI green, docs swept (tracker, hand-off, [load testing](../../05-quality/load-testing.md)
when a load result changes).
