# Pricing Validation Plan

> [Docs index](../../README.md) › [01-product](../README.md) › [discovery](README.md)

**Goal:** validate plan packaging and price points from [business-model-and-pricing.md](../business-model-and-pricing.md) with ≥ 5 prospects **before** building billing. Exit: ≥ 3 prospects accept Starter or Professional price; ≥ 1 signed pilot LOI.

## Method
1. **Value first:** ask what fuel loss, ticket disputes and breakdowns cost them per month (from the interview).
2. **Van Westendorp questions** (per plan, show the plan card):
   - At what monthly price per site would this be **so cheap** you'd doubt its quality?
   - …a **bargain**?
   - …**getting expensive** but still worth considering?
   - …**too expensive** to consider?
3. **Packaging test:** which features would they drop to pay less, and which would they pay extra for (AI copilot, edge agent, telematics)?
4. **Commitment test:** "Would you sign a 3-month paid pilot at €X per site?" Record the answer as yes / conditional / no.

## Record

| Prospect | Segment | Sites | Machines | Too cheap | Bargain | Expensive | Too expensive | Plan chosen | Commitment |
|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | |

## Decision rules
- Set each plan's price within the range between the median "bargain" and "expensive" answers for its target segment.
- If ≥ 50 % of S1 prospects say Starter is too expensive, test a 10-asset "Essentials" tier rather than discounting.
- Record the final price book v1 in [business-model-and-pricing.md](../business-model-and-pricing.md) with the date and evidence.
