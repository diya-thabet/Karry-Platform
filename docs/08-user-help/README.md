# 08-user-help — End-User Help Articles

> [Docs index](../README.md)

Help articles for Karry customers, one file per task, mirrored in both languages:

```
08-user-help/
├── fr/<role>/<task>.md      e.g. fr/operator/start-a-shift.md
└── en/<role>/<task>.md      e.g. en/operator/start-a-shift.md
```

Rules: same file name in `fr/` and `en/`; written for field users (short sentences, screenshots, numbered steps); created in the same PR as the feature (see [llm_guidelines.md §19](../00-llm/llm_guidelines.md#19-documentation-policy)). First articles arrive in Phase 2.
